# Oopz 文字上屏重构

## 已确定的产品约定

- 保持 Windows 单文件程序、托盘入口、手动选择文字频道、F8 输入、F9 显示切换。
- 输入结束后恢复先前窗口；点击其他窗口立即退出输入，不把用户拉回游戏。
- 透明 HUD 保持位置、大小和文本布局；平时鼠标穿透，激活时可选择文本和滚动历史。
- 紧凑单页设置；设置即时生效；位置编辑只有完成时保存，取消恢复。
- 保留系统托盘通知，合并重复异常；发送失败保留草稿，下一次输入可恢复。
- 保留文字与背景透明度、字号、新消息高亮、版本与更新状态。

## 架构边界

1. 通信：单线程 asyncio 管理连接；换频道、账号、凭据产生新会话。旧请求和旧事件不能进入新会话。
2. Windows：统一管理输入激活、焦点归还、快捷键和滚轮。静止 HUD 不激活窗口、不修改其他窗口大小。
3. 界面：设置与 HUD 分离；原生文本布局、光标、选区和输入法；描边只影响绘制。
4. 应用：接受带会话标识的事件，保存设置和失败草稿，区分连接、列表读取和发送错误。

## 基线查证

- 并发连接共用客户端和频道字段，没有会话隔离。
- WebSocket 重连后没有恢复状态或补取断线历史。
- 连接键不含凭据；同一频道刷新凭据可能不重连。
- 设置页可见时读取登录态只更新控件，已有频道未必真正连接。
- 焦点层混用强制切换 API；延迟恢复未检查用户是否已经切换窗口。
- 全局滚轮钩子常驻，回调同步调用界面。
- 输入另绘文字，与原生选取和输入法布局可能不同步。
- 新消息重建全部消息行，容易干扰滚动和选择。

## 验收

- 连续切频道、过期请求、断线重连补历史、鉴权失败、发送拒绝、失败草稿。
- 中文输入法、长文本、选取、Enter/Esc、点击其他窗口、快捷键冲突。
- 重复输入不改变目标窗口位置、大小、最大化和置顶状态。
- 静止和失焦时不捕获鼠标；多屏与缩放下保持可见。
- Windows 虚拟机原生测试及打包启动；实际游戏和 Oopz 收发验证单独记录。
