# 纸条 0.11.0 系统提示音

日期：2026-09-28。

## 行为

- 设置页新增「消息提示音」选择和「试听」，新用户及从旧版本升级均默认关闭。
- 从运行电脑的 Windows Media 目录读取已安装的 WAV 声音，包含主题子目录。保存相对文件名，不打包音频，也不增加播放依赖。
- 仅当前频道别人新发的实时消息播放；历史加载、重复消息、已有消息更新、本人消息和过期会话事件不播放。批量消息只触发一次。
- 播放异步执行；提示音正在播放时不叠加。试听允许中断前一次试听。声音缺失或音频设备不可用不影响消息处理。
- 声音设置即时保存。之前选择的文件已不存在时显示「所选声音不可用」，保留该选择，允许重新选择或关闭。
- 升级后通知 Windows 外壳更新原程序文件的图标；保留原启动路径、更新入口和绿色纸条图标。

## 图标核对

修改前，用户原启动入口 `D:\system-files\Downloads\OopzTacticalOverlay.exe` 已是 0.10.2，SHA-256 与公共发行包相同。直接提取其内嵌图标，以及在交互式 Windows 桌面查询程序与开始菜单快捷方式，均得到绿色纸条图标。

附件中的黄色 O 是旧样式，但仅凭该截图不能确定具体文件或界面缓存的来源。开始菜单快捷方式仍正确指向原启动文件。本次仅通知原程序文件发生更新，没有删除全局图标缓存或重启 Explorer。

## 技术依据

- [Python winsound](https://docs.python.org/3/library/winsound.html)：文件播放、异步返回和忙时不打断。
- [Windows SHChangeNotify](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shchangenotify)：通知外壳单个文件发生更新。
