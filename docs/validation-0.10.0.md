# 纸条 0.10.0 交付与验证

日期：2026-09-26。

此版本随后由 [0.10.1](validation-0.10.1.md) 替代。用户原入口验收发现继承自旧版的跨磁盘更新问题，修复与最终交付记录见新版本。

## 实际交付

- 产品改名为「纸条」：设置窗口、托盘、通知、启动错误提示、应用图标和 Windows 文件属性统一更新。
- 设置页重新组织为频道、实时预览、显示调整和快捷键；跟随系统明暗主题，窄窗口改为纵向布局。
- 平时 HUD 只留昵称与消息；输入时出现频道与输入行，回看时出现时间和返回最新的操作，失败草稿恢复时标记「未发送」。
- 预览与实际 HUD 共用消息、输入和历史导航组件。亮景、暗景与状态切换只影响演示，不发送聊天消息，也不写入用户设置。
- F8、F9、Enter、Esc、鼠标穿透、历史滚动、焦点恢复、手动选择频道和失败草稿规则保持兼容。
- 原设置目录、单实例标识、旧程序入口与更新地址保留，已有用户通过原入口升级。

## 回归与原生窗口

- macOS / Python 3.13 / Qt 6.11.1：74 项通过，3 项 Windows 专用检查跳过。
- 原生 Windows x64 / Python 3.11 / Qt 6.11.2：77 项通过。
- Windows 11 ARM64 / Python 3.11 x64 / Qt 6.11.1：77 项通过。
- 独立 Windows 桌面的 16 轮 F8、Enter、Esc 检查通过；普通和最大化测试窗口的位置、大小、焦点均恢复正常。
- 主动输入时滚轮翻历史；点击「回到最新」保留草稿与输入焦点；被动状态不拦截滚轮；F9 不抢焦点。
- 实际 Qt 明暗界面、440 像素窄窗口、透明 HUD 均已渲染和检查；修复预览旧行延迟销毁造成的重影与父样式覆盖消息颜色的问题。

## 自动升级

在独立 Windows 用户状态目录运行原始 0.9.1，使用真实公共更新地址，以下检查通过：

1. 旧版识别、下载和校验 0.10.0；运行中的旧文件保持不变。
2. 正常退出再启动后，由原更新助手替换原文件并打开「纸条」。
3. 待更新记录清除，没有更新错误记录；新文件与公共清单校验一致。
4. 原有字号、透明度、背景、快捷键等设置完整保留。
5. 新版正常退出并释放 F8/F9。

测试环境沿用仅对测试进程提供的官方 ISRG Root X1，未关闭 TLS 校验或修改系统信任库，证书说明见 [0.9.1 升级记录](validation-update-0.9.1.md)。首次测试的两分钟等待上限短于虚拟机下载耗时；延长测试等待时间后完整升级通过，未更改程序的下载逻辑。

本次没有向真实 Oopz 频道发送测试消息。通信与账号隔离继续由既有回归覆盖；此前的真实收发验证见 [0.9.1 记录](validation-0.9.1.md)。原生焦点检查使用独立测试窗口，不等于实际游戏、独占全屏或反作弊环境的验证。混合 DPI、多显示器热插拔和长期运行仍需对应环境验证。
