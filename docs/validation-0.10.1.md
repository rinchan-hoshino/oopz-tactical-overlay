# 纸条 0.10.1 最终交付

日期：2026-09-26。包含 [0.10.0 的原生界面重做](validation-0.10.0.md)，并修复原安装入口验收发现的跨磁盘更新问题。

## 跨磁盘更新

用户的程序在 D 盘，配置和更新缓存位于 C 盘。旧助手直接执行 `os.replace(source, target)`，在该环境返回 `WinError 17 / EXDEV`，随后把失败笼统记为文件被占用。只在同盘测试无法覆盖这个问题。

现在先把已经校验的下载文件复制到安装目录旁的临时目录，再校验该副本，最后在同一磁盘原子替换程序。复制失败或校验不符时保留旧程序；临时目录自动清理。

旧助手本身不具备这一修复，跨盘旧安装需要一次由已验证的新助手完成迁移。此后沿用原启动检查、下载和下次启动替换的流程，配置与安装位置不变。
